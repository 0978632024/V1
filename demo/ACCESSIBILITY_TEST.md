# TapThrough 無障礙與 R2 檢查表

檢查日期：2026-09-05。自動測試平台：Windows Microsoft Edge（Chromium）headless。這些結果不是 WCAG 認證，也不替代 VoiceOver／TalkBack 實機測試。

## 已執行

- [x] Build：產生可直接開啟的單檔 HTML 與 Service Worker；無執行期外部依賴。
- [x] 7 組模型測試：R2 正常路徑／20 元、無效轉移與份數、120 秒提醒與600秒逾時、逾時中收到付款、免學期文件、12 畫面與 11 價目、固定假身分與尺寸函式。
- [x] 瀏覽器正常路徑：語言→學生→驗證→文件→份數→名次→114-2→確認→現金→付款→處理→列印→取件。
- [x] 無 machine／未知 machine／demo 與引導模式路由。
- [x] 表單錯誤 aria-invalid、aria-describedby、錯誤焦點與不回音敏感值。
- [x] 每次換頁焦點在新 h1；鍵盤 Tab / Enter 操作；有意義的按鈕名稱與至少44px按鈕。
- [x] 隱私模式隱藏像素但保留主要 accessibility tree 與按鈕。
- [x] 手機 320、375、390、430px 檢查；320px／200% 文字与設定 Dialog 檢查無橫向溢出。
- [x] Dialog Escape 關閉、焦點回到設定按鈕。
- [x] 付款失敗→恢復→付款成功→處理→列印。
- [x] 推進時間：120 秒提醒、600 秒逾時、明確確認才恢復。
- [x] 語音辨識不支援與權限拒絕後，按鈕流程仍可完成。
- [x] 辨識結果只顯示為文字；必須確認學期後才前進。
- [x] TTS 替身：預設不播放，啟用手勢解鎖，cancel 後至少150ms排程，隱私模式停止播音。
- [x] file:// 單檔開啟與離線流程；HTTP 快取後離線重新載入。
- [x] 重新整理不還原身分或交易，只保存機台尺寸。
- [x] 正常瀏覽器流程無未捕捉 JavaScript 錯誤。
- [x] 檢查 CSS 有 prefers-reduced-motion；測試瀏覽器以 reduced motion 運行。

## 必須現場實測：iPhone Safari + VoiceOver

- [ ] 記錄 iOS／Safari 版本、機型、是否戴眼罩、A/B 版本、實際起訖時間。
- [ ] 先載入網址完成快取，切飛航模式關閉頁面再開；確認離線引導仍可用。iOS 檔案預覽與 Safari 分開驗證。
- [ ] VoiceOver 開啟、Demo TTS 與「直接滑動切換」關閉，左右滑動順序正確，雙擊所有主要按鈕能完成整條 R2 流程。
- [ ] 轉子以標題導覽可到目前 h1，每次換頁唸出新步驟，無殘留在已移除控制的焦點。
- [ ] Radio 份數、輸入欄、Dialog 皆有清楚名稱、值與狀態。
- [ ] aria-live：連接、已加入文件、等待付款、成功、處理、列印、錯誤都能聽見且不重複轟炸。
- [ ] 敏感步驟不把學號／生日放進 live region，不播放網站 TTS。確認金額由讀屏自選閱讀。
- [ ] 黑屏後仍能滑到選項並雙擊；能找到關閉隱私模式按鈕，無法从畫面看到敏感資訊。
- [ ] 200% 系統文字與直向320px等效視窗，沒有遮住主要動作。
- [ ] 啟用 Demo TTS（先關 VoiceOver）：第一次按鈕就能解鎖；連續重播、停止、換頁不殘留舊語音。
- [ ] 逐句聽見三句貼紙知識，所有距離為【待填】，不得憑空口述數字。
- [ ] 關閉網路後測試系統 zh-TW 音色；若音色無法離線播音，改用已驗證讀屏／錄音備援。
- [ ] 真實 SpeechRecognition 同意／拒絕／無聲／中断，確認文字後才前進；不支援時按鈕可完成。
