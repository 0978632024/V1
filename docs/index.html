交件指南

給 星語、小恩、阿崴 三位。你不需要裝任何東西、不需要 GitHub、不需要碰 git —— 打開瀏覽器填一張表單就好。

交件表單點這裡開始填 →

一次交一個主題。表單的必填欄位填不完整就送不出去，所以你不會遇到「交了才被退回」。

交完請在群組貼一行：「我交了什麼、哪一類」。表單雖然會寄信給 A／B，但三天活動裡群組 @ 一下最可靠，不要省這一步。

01一定要回答的三個問題

  1. 這是什麼？
  2. 要放提案哪一節？
  3. 資料來源是什麼？

三天內會有幾十份文件。沒有這三個答案，我們分不出來該放哪、只能整份退掉 —— 表單設成必填就是為了讓你不用擔心這件事。

02你可以交三種東西

表單第 2 題選一個，後面的問題會自動跟著換。下面列的是每一類會問你什麼，可以先想好再開表單。三類都不是的話選「其他」自己描述。

研究素材 DAY 1–2

競品、市場數據、使用者訪談。

  • 我查到什麼（一行）
  • 具體內容，每條都要有出處
  • 這對提案有什麼用（我的看法）
  • 我查了但沒查到的
  • 附件
QA 回報 DAY 2–3 ・ 對名次貢獻最大

把 demo 拿去玩，找出評審看到會出事的地方。這件事不需要任何權限，也不會弄壞任何東西。請用電腦測 —— 評審看到的就是電腦畫面，手機測不到的問題比較多。

  • 裝置／瀏覽器
  • 測哪個版本或網址
  • 我做了什麼（一步一步）
  • 我以為會發生什麼
  • 實際發生了什麼
  • 嚴重程度
  • 截圖／錄影
  • 我建議怎麼改
  • A 級評審看到會當場出戲 —— 跑不起來、算錯、卡住、亂碼
  • B 級難用，但不會壞
  • C 級只是我覺得可以更好

三天內我們只保證修 A 級。B 級和 C 級照樣寫 —— 有空會修，也可能寫進提案的「下一步」那一節。

提案段落 DAY 2

提案的任何一節都可以寫，不用等人分配，重複也沒關係 —— 三個人寫同一節，我們就有三個版本可以挑。

  • 這一節唯一要說的一句話
  • 內文，3–6 句，不要更長
  • 如果只放一張圖或一個數字，放什麼
  • 哪份研究素材支持這段
其他 隨時

上面三類都不是的話走這裡，自己描述那是什麼。

  • 那是什麼（自己描述類型）
  • 內容
  • 附件連結
最重要的一段

用 ChatGPT / Gemini 的注意事項

不要交「AI 一次生出來的完整章節」。那種東西讀起來每句都對，但沒有一句能用在提案裡 —— 我們只能整段重寫，你這份就白做了。

要交的是有出處的東西：具體的數字、名稱、報價，或真人說過的話。

✕ 會被退

「AI 助理市場正快速成長，預計未來幾年將持續擴大。」

✓ 能用

「Gartner 2025/11 報告：XX 市場 2026 年 $X 億，年增 X%。」＋ 連結

✕ 會被退

「主要競品包括多家國內外廠商。」

✓ 能用

「競品 A：月費 $299、缺 XX 功能。競品 B：免費但要自架。」（我實際註冊試用過）

✕ 會被退

「使用者普遍希望操作能更簡單。」

✓ 能用

「我問了 3 個在做這件事的人，其中 2 個說『每次都要重新設定一遍很煩』。」

AI 的正確用法是幫你整理與潤稿，不是幫你生內容。先自己找到具體的數字、名稱、報價、真人說的話，再叫 AI 幫你排成表單要的格式。

03你不會碰到的東西

demo 的程式碼和簡報主檔由 A／B 收口。你交的東西在 A 或 B 看過之前，不會動到它們任何一個字。

想改 demo 的哪裡 → 寫 QA 回報，不要自己動手。這不是不信任你 —— 是三天內任何人直接改 demo，都可能讓它在評審面前跑不起來。

04看大家在幹嘛

戰情看板 —— 五個人現在各自在做什麼，開著放旁邊就好，會自己更新。

你交件之後，你的角色會跳起來。橘色格子＝今天的動作數，滿 5 格會升級換色。

一句話總結

交小、具體、有出處的東西，一次一個主題。Day 2 開始用電腦把 demo 拿去玩，找出「評審看到會出戲」的問題 —— 那是你對名次貢獻最大的事。
